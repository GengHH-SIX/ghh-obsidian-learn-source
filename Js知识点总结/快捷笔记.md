Reflect
1. new Foo(...args) == Reflect.construct(Foo, args)
2. const ins = Reflect.construct(A, args，B) NewFunc存在时，则为实例ins真实构造器；但是执行的是构造函数A中的代码。相当于给ins换了个壳！
	- `ins instanceof A  // false;`
	- `ins instanceof B  //true;`

Symbol
1.  `\[Symbol.iterator\]()` 此函数定义对象是个可迭代对象，会被[`for...of`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Statements/for...of) 循环、[数组和参数扩展](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/Spread_syntax)、[`yield*`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/yield*) 和[数组解构](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/Destructuring) 在内部使用应该
	- 内置的可迭代对象（内置存在这个的对象）
		-  Arguments
		-  [`Array.prototype[Symbol.iterator]()`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Array/Symbol.iterator)
		- [`TypedArray.prototype[Symbol.iterator]()`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/TypedArray/Symbol.iterator)
		- [`String.prototype[Symbol.iterator]()`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/String/Symbol.iterator)
		- [`Map.prototype[Symbol.iterator]()`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Map/Symbol.iterator)
		- [`Set.prototype[Symbol.iterator]()`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Set/Symbol.iterator)
		- [`Intl.Segments`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Intl/Segmenter/segment/Segments)
		- [`NodeList`](https://developer.mozilla.org/zh-CN/docs/Web/API/NodeList)
