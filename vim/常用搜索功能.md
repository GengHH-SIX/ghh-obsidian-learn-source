
### 一 .`t`、`f`、`T`、`F` 是 Vim 原生的‌**==**行内**字符==查找指令**‌。

#### 1、核心功能对比

这四个指令都用于在‌==**当前行**‌==内快速跳转光标，区别在于方向和目标位置：

| 指令        | 全称            | 方向  | 停止位置          | 示例 (`  | `为光标, 搜索 `x`)          |                  |
| :-------- | :------------ | :-- | :------------ | :----- | ---------------------- | ---------------- |
| ‌**`f`**‌ | Find          | 向后  | ‌**停在**‌目标字符上 |  `abc  | xdef` -> `fx` -> `abcx | def`             |
| ‌**`t`**‌ | Till          | 向后  | 停在目标字符‌**前**‌ |  `abc  | xdef` -> `tx` -> `abc  | xdef` (光标在 x 左边) |
| ‌**`F`**‌ | Find Backward | 向前  | ‌**停在**‌目标字符上 |  `abcx | def` -> `Fx` -> `abc   | xdef`            |
| ‌**`T`**‌ | Till Backward | 向前  | 停在目标字符‌**后**‌ |  `abcx | def` -> `Tx` -> `abcx  | def` (光标在 x 右边)  |
|           |               |     |               |        |                        |                  |

#### 2、详细用法说明

1. ‌**`f{char}` / `F{char}`（精准定位）**‌
    
    - 直接跳转到指定字符的位置。
    - 适合直接对该字符进行操作（如删除 `dfx` 删除到 x）。
2. ‌**`t{char}` / `T{char}`（留有余地）**‌
    
    - 跳转到指定字符的‌**前一个/后一个位置**‌。
    - ‌**核心优势**‌：常用于配合操作符。例如 `dt.`（删除直到句号前），保留句号不被删除，比 `df.` 更常用且安全。

#### 3、进阶技巧：重复与反向

- ‌**`;` (分号)**‌：重复上一次 `f/t/F/T` 查找，方向不变。
- ‌**`,` (逗号)**‌：重复上一次查找，但‌**反向**‌执行。
    - 例如：执行 `fx` 后，按 `;` 会找下一个 `x`，按 `,` 会找上一个 `x`。


### 二 .`*`、`#` 是 Vim 原生的‌**==单词==查找指令**‌。

- **==`*`==**：向前（向下）搜索当前光标下的**完整单词**
- **==`#`==**：向后（向上）搜索当前光标下的**完整单词**

### 三.  `?` 指令行里自行输入查询

- **==`enter`==**： 全文搜索当前输入下的**完整内容**
- **==`N`==**：向下 挨个跳转，已经查询过的**内容**
- **==`n`==**：向上 挨个跳转，已经查询过的**内容**
